# gRPC_AXCF2152
A brief tutorial on how to use gRPC to interface Python and PLCnext Engineer projects to access (read/write) process data.

The instructions on how to make use of the files in this repository are explained in the following Maker's Blog post from the PLCnext community: https://www.plcnext-community.net/makersblog/use-grpc-to-interface-python-scripts-with-plcnext-engineer-projects/
